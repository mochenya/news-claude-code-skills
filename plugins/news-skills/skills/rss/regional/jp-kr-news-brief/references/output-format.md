# 日本·韩国新闻简报排版与输出规范

本文件是 `jp-kr-news-brief` 的唯一成稿合同。候选集完成时间过滤、相关性筛选和语义去重后，起草前必须完整读取并执行本文件。

## 一、选择输出模式

### 标准政经简报（默认）

适用于“日韩新闻”“日韩政治经济动态”“隔夜日韩简报”等一般请求。正文根据实际新闻动态分区，不强制加入股市盘面。

### 午间／收盘市场简报

用户明确提出“午间”“盘中”“收盘”“收盘后”“股市表现”或“市场分析”时启用。在标准政经简报基础上，必须增加 `📊 股市与市场表现` 板块。

- **盘中**：市场尚未收盘时，所有行情写明“截至 HH:mm”，不得使用“收盘”措辞。
- **收盘**：仅在北京时间 14:30 后，且已获取可靠收盘数据时使用“收盘表现”。
- 用户未要求市场简报时，不因个别股票新闻自动添加完整盘面板块。

## 二、通用成稿要求

- 全程中文，短句优先，事实和影响前置。
- 只输出简报正文，不输出抓取、筛选、翻译或核验过程。
- 全部时间换算为北京时间（UTC+8）。
- 每条新闻必须附 Markdown 来源链接，不得出现裸 URL。
- 同一事件只写一条；多源信息互补时合并叙述并并列来源。
- 按政策、市场和产业影响排序，不按发布时间机械排序。
- 高价值新闻少就少写，不为凑条数降低门槛。
- 单方说法、预测和未证实信息必须使用“称”“据报道”“尚未获独立证实”等限定语。

## 三、标题、摘要与来源

### 标题

采用“主体＋动作＋结果”结构，一般控制在 20–30 个中文字内。

```text
✅ 日本央行维持政策利率不变，下调增长预测
✅ 韩国出口连续第三个月增长，芯片需求继续回升
❌ 日本央行发布了备受关注的最新决定
❌ 值得关注的韩国出口数据出现变化
```

### 摘要

通常写 2 句：

1. 第一句交代新增事实，包括主体、动作、数字和结果。
2. 第二句说明对政策预期、汇率、利率、产业链或风险偏好的直接影响。

必要背景只保留理解当前变化所需的一层。不得逐句翻译 RSS 摘要，也不得把无依据推演写成事实。

### 单条格式

```markdown
1️⃣ **{主体＋动作＋结果}**
{新增事实。对政策、市场或产业链的直接影响。}
📅 YYYY-MM-DD HH:mm · 🔗 [来源1](URL) | [来源2](URL)
```

来源名称使用简短标准写法，例如 `[Nikkei Asia]`、`[Japan Times]`、`[Yonhap]`、`[Korea Herald]`。

## 四、动态分区与排序

根据本窗口新闻的实际成分建立 2–5 个板块。以下名称仅供选择，不要求全部出现：

| Emoji | 参考板块 | 典型内容 |
|---|---|---|
| 🔥 | 政治与宏观政策 | 内阁、议会、财政、税制、央行、汇率政策 |
| 🌏 | 外交与区域安全 | 美日、美韩、中日、朝鲜、经济安全 |
| 🏭 | 产业链与科技 | 半导体、电池、造船、汽车、AI、出口管制 |
| ⚡ | 能源与资源 | LNG、核电、原油进口、电力政策、关键矿产 |
| 📊 | 股市与市场表现 | 指数、汇率、利率、板块轮动和盘面驱动 |

板块和条目均按重要性降序。政治、央行、财政、监管及重大外部冲击通常优先于一般企业新闻。

## 五、午间／收盘市场板块

### 必备内容

在数据可得时依次覆盖：

1. **日本股市**：日经 225、东证指数，以及主要领涨／领跌板块。
2. **韩国股市**：KOSPI、KOSDAQ，以及半导体、电池、汽车等核心板块。
3. **汇率与利率**：美元兑日元、美元兑韩元；日本或韩国国债收益率仅在有显著变化时加入。
4. **盘面驱动**：将市场变化与本窗口内的央行、政策、贸易、企业盈利或外部风险新闻对应起来。

### 数据和归因纪律

- RSS 候选集是新闻主来源，指数、汇率和利率数据可通过 `web_search` / `web_extract` 补充。
- 优先使用交易所、央行、Reuters、Bloomberg、Nikkei、Yonhap 等可追溯来源。
- 每组行情必须注明数据时点和来源。
- 盘中价格不得冒充收盘价；不同时间点的数据不得拼成同一时点快照。
- 有来源明确归因时可写“主要受……推动”；仅为合理推断时写“可能与……有关”。
- 无可靠行情数据时写“截至成稿未取得可核验盘面数据”，不得补造点位、涨跌幅或成交额。

### 板块格式

```markdown
📊 **股市与市场表现**

- **日本**：截至 HH:mm，日经 225 报 {点位}，涨跌 {幅度}；东证指数 {表现}。{板块表现与主要驱动。}
- **韩国**：截至 HH:mm，KOSPI 报 {点位}，涨跌 {幅度}；KOSDAQ {表现}。{板块表现与主要驱动。}
- **汇率与利率**：美元兑日元 {数值}，美元兑韩元 {数值}；{如有关键利率变化}。
- **盘面判断**：{区分已报道驱动与谨慎推断，不重复前文。}

📅 数据截至 YYYY-MM-DD HH:mm（UTC+8） · 🔗 [来源1](URL) | [来源2](URL)
```

如果市场变化本身是当期最重要事件，本板块可以置顶；否则放在主要政策板块之后、产业板块之前。

## 六、潜在海外投资观察

简报末尾固定加入该板块，通常写 2–4 点：

```markdown
**潜在海外投资观察**

- {由本窗口新闻支持的政策、汇率、利率或产业链信号}
- {需要继续跟踪的明确变量或时间点}
```

要求：

- 每一点都必须能追溯到本窗口新闻或本次市场数据。
- 只提示政策、行业和市场传导，不给出主观买卖建议。
- 不重复正文，不用历史背景或上期内容填空。
- 没有可靠信号时只写“暂无明确线索”。

## 八、零条目窗口

窗口内没有有效新闻时，不得加入窗口外旧闻：

```markdown
# 日本·韩国政治经济简报
📅 追踪区间：{开始时间} – {结束时间}（UTC+8）
📊 共 0 条

本窗口内未发现符合筛选标准的日本、韩国政治经济重要新闻。

**潜在海外投资观察**：暂无明确线索
**生成时间**：YYYY-MM-DD HH:mm UTC+8
```

- [ ] 同一事件已合并，不存在 Yonhap 双频道重复
- [ ] 每条均有北京时间和 Markdown 来源链接
- [ ] 午间数据标注“截至”，收盘数据确为收盘价
- [ ] 行情事实与盘面归因已区分
- [ ] 潜在海外投资观察均有本窗口依据
